==============================================
  足迹地图 · 分享 / 部署 / 安装成 App 教程
==============================================

这个项目现在是一个「PWA」（渐进式网页应用），
发布到网上之后，别人可以：
  1. 用网址打开使用
  2. 把网址「安装」到手机/电脑桌面，像 App 一样用

⚠️ 注意：PWA 的「安装」功能必须发布到网上（https）后才能用，
    直接双击本地文件打开时，它就是个普通网页，不影响使用。

------------------------------------------------
一、免费发布（三选一，推荐 Vercel 最简单）
------------------------------------------------

【方式 A：Vercel（最简单，推荐）】
  1. 打开 https://vercel.com 用 GitHub 账号登录（没有就注册一个）
  2. 点「Add New → Project」
  3. 把 D:\足迹地图 这个文件夹整个拖进去，或先传到 GitHub 再导入
  4. 点 Deploy，等几秒就生成一个网址，直接分享

【方式 B：GitHub Pages】
  1. 注册 GitHub（github.com），新建一个仓库（如 footprint）
  2. 把 D:\足迹地图 里的文件全部上传到仓库
  3. 仓库 Settings → Pages → 选 main 分支 → Save
  4. 生成网址：https://你的用户名.github.io/footprint/

【方式 C：Gitee Pages（国内，更快）】
  1. 注册 Gitee（gitee.com），新建仓库
  2. 上传 D:\足迹地图 里的所有文件
  3. 服务 → Gitee Pages → 启动
  4. 生成国内可访问的网址

------------------------------------------------
二、安装成 App（发布之后）
------------------------------------------------

  手机端：
    用浏览器打开你发布的网址 → 点浏览器菜单 → 「添加到主屏幕」
    （iOS Safari：分享按钮 → 添加到主屏幕；安卓 Chrome：菜单 → 安装应用）

  电脑端：
    用 Edge/Chrome 打开网址 → 地址栏右侧出现「安装」图标 → 点它安装

------------------------------------------------
三、上线前的提醒（重要）
------------------------------------------------

  1. 高德瓦片目前是「无密钥」用法，个人学习可以；
     如果以后要正式对外/商用，去高德开放平台申请免费 API key，
     把 key 加进瓦片链接里。
  2. 数据仍存在「每个人的浏览器」里，多人之间互不可见；
     要做成「云同步、多人互动」需要加后端（下一步可以学）。
